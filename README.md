# AGARIS — Web editorial

Rediseño de AGARIS inspirado en una dirección editorial/corporativa: tipografía grande, bloques, ritmo vertical, azul marino y crema, sin depender de fotografías de stock.

## GitHub Pages
Sube `index.html`, `style.css`, `script.js` y `assets/` al repositorio `agaris`.
Si Pages ya está activo en `main / (root)`, no hay que cambiar nada más.

## Formspree
En `index.html`, sustituye `action="#"` del formulario por tu endpoint real de Formspree.

## Datos pendientes
Antes de publicar como versión definitiva, sustituir teléfono, email y textos legales por los datos reales del despacho.
