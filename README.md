# AGARIS — Web definitiva

Web corporativa responsive preparada para GitHub Pages.

## Archivos
- `index.html`
- `style.css`
- `script.js`
- `assets/agaris-logo.png`

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta al repositorio `agaris`.
2. Ve a Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`.
5. Folder: `/ (root)`.
6. Guarda.

Si GitHub Pages ya está configurado, solo necesitas sustituir los archivos antiguos por estos y hacer Commit changes.

## Formulario
Sustituye `action="#"` en `index.html` por tu endpoint real de Formspree.

## Antes de publicar definitivamente
Sustituir por datos reales:
- teléfono;
- email;
- profesionales/equipo;
- artículos de actualidad;
- aviso legal, privacidad y cookies.

No se han incluido cifras, clientes, años de experiencia ni credenciales que no hayan sido facilitados.
