# AGARIS — Web v2

Versión rediseñada de la web corporativa de AGARIS, siguiendo la dirección visual aprobada:
- estética híbrida jurídica + empresarial;
- paleta crema / carbón / verde oscuro;
- menos apariencia de plantilla;
- hero arquitectónico abstracto;
- tipografía editorial;
- secciones más limpias;
- interacción real en servicios;
- responsive para móvil.

## GitHub Pages
Sube `index.html`, `style.css`, `script.js` y `assets` al repositorio.
Después: Settings → Pages → Deploy from branch → rama principal → `/root`.

## Formspree
En `index.html`, sustituye `action="#"` del formulario por el endpoint real de Formspree.

## Datos pendientes
Teléfono, email definitivo, profesionales/equipo, redes sociales, textos legales y cualquier referencia de clientes deben sustituirse por datos reales.
