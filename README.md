# AGARIS — Web final

Web estática lista para GitHub Pages.

Archivos:
- index.html
- style.css
- script.js
- assets/agaris-logo.png

## Publicar
1. Sube todos los archivos al repositorio.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: / (root).
6. Save.

## Formulario
Sustituye `action="#"` en `index.html` por el endpoint real de Formspree.

## Datos pendientes
El teléfono, email, equipo, referencias de clientes y textos legales son placeholders y deben sustituirse por datos reales antes de publicar definitivamente.
